# Java 学习笔记

一套面向 Java 初学者的中文学习笔记，涵盖 Java 基础、面向对象、集合、常用 API、正则表达式、查找与排序算法以及多线程/并发等核心知识点。全部内容以 Markdown 编写，配有大量示意图和代码示例，适合自学者系统复习或作为教学参考。

## 主要知识点

- **Java 基础**：ArrayList、泛型、常用 API（String、StringBuilder、包装类、JDK7/JDK8 时间类）
- **面向对象**：封装、继承、多态，以及综合练习项目（学生管理系统、拼图游戏等）
- **集合框架**：Collection 体系、迭代器、源码分析（LinkedList、HashMap）、二叉树 / 红黑树 / 哈希表原理
- **算法**：基本查找、二分查找，冒泡 / 选择 / 插入 / 快速排序（含动图）
- **进阶**：正则表达式、Stream 流、Lambda、多线程与并发（CAS、ConcurrentHashMap、Semaphore、CyclicBarrier、线程池等）
